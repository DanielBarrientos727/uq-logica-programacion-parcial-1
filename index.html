Ejercicio 1A — Restricción de Atracción

E1a.java
¿Qué problema intenta resolver?

Valida si una persona puede ingresar a una atracción de un parque de diversiones evaluando su edad y su estatura, permitiendo el ingreso bajo condiciones estándar o por acceso especial para adultos mayores.

Datos de entrada
  • Edad: Número entero (`int`) ingresado por teclado.
  • Altura: Número con decimales (`double`) ingresado por teclado (ej. `1.45`).
Proceso y Lógica Utilizada

Se utiliza una estructura condicional compuesta con operadores lógicos (`&&` y `||`) dentro de la función calculoRestriccion:

  • Se verifica si edad >= 12 y altura > 1.40.
  • Se aplica una condición alternativa con if (edad > 60) para otorgar acceso especial sin importar la estatura.
Resultado Esperado

Retorna y muestra en consola un mensaje de texto indicando si el usuario puede ingresar ("Bienvenido, puede ingresar a la atracción") o si es denegado ("No puede ingresar a la atracción :(").

Explicación Sencilla del Código

El programa inicia en el método main utilizando la clase Scanner (a través de funciones auxiliares) para capturar los datos del usuario. Estos datos se envían como parámetros a calculoRestriccion(int edad, double altura), la cual procesa la lógica condicional y devuelve un String que luego se imprime mediante generarMensaje().

Código Java (E1a.java)
E1a.java 
import java.util.Scanner;

public class E1a {
    
    public static void main(String[] args) {
        int edad = ingresarEntero("¿Cuál es su edad?");
        double altura = ingresarRealD("¿Cuál es su altura?");
        String restriccion = calculoRestriccion(edad, altura);
        generarMensaje(restriccion);
    }

    public static int ingresarEntero(String mensaje) {
        Scanner sc = new Scanner(System.in);
        System.out.print(mensaje);
        int valor = sc.nextInt();
        return valor;
    }

    public static double ingresarRealD(String mensaje) {
        Scanner sc = new Scanner(System.in);
        System.out.print(mensaje);
        double valor = sc.nextDouble();
        return valor;
    }

    public static String calculoRestriccion(int edad, double altura) {
        String mensaje = " ";

        if (edad >= 12 && altura > 1.40) {
            mensaje = "Bienvenido, puede ingresar a la atracción";
        } else {
            mensaje = "No puede ingresar a la atracción :(";
        }

        if (edad > 60) {
            mensaje = "Bienvenido, puede ingresar a la atracción";
        }

        return mensaje;
    }

    public static void generarMensaje(String restriccion) {
        System.out.println(restriccion);
    }
}

Ejercicio 1B — Descuento en Tienda Deportiva

E1b.java
¿Qué problema intenta resolver?

Determina si un cliente aplica para una promoción o descuento especial en una tienda deportiva en función del valor de su compra, si es cliente frecuente o si supera cierta edad.

Datos de entrada
  • Valor de la compra: Número decimal (`double`).
  • Cliente frecuente: Valor booleano (`boolean` -> true o false).
  • Edad: Número entero (`int`).
Proceso y Lógica Utilizada

La función calculoDescuento evalúa dos criterios principales:

  • Si valorCompra > 200000 y clienteFrecuente == true, aplica al descuento.
  • Si edad > 65, también se le otorga el beneficio de forma directa.
Resultado Esperado

Imprime en consola si el usuario aplica o no a la promoción ("Para la promoción usted aplica para el descuento").

Explicación Sencilla del Código

Demuestra el uso de tipos de datos variados (`double`, boolean, `int`), métodos de lectura especializados como nextBoolean(), y operadores relacionales y lógicos dentro de estructuras condicionales anidadas.

Código Java (E1b.java)
E1b.java 
import java.util.Scanner;

public class E1b {

    public static void main(String[] args) {
        double valorCompra = ingresarRealD("¿Cuál el valor de la compra? ");
        boolean clienteFrecuente = ingresarBoolean("¿Es un cliente frecuente? ");
        int edad = ingresarEntero("¿Cuál es la edad del cliente? ");
        String valorFinal = calculoDescuento(valorCompra, clienteFrecuente, edad);
        generarMensaje(valorFinal);
    }

    public static double ingresarRealD(String mensaje) {
        Scanner sc = new Scanner(System.in);
        System.out.print(mensaje);
        double valor = sc.nextDouble();
        return valor;
    }

    public static int ingresarEntero(String mensaje) {
        Scanner sc = new Scanner(System.in);
        System.out.print(mensaje);
        int valor = sc.nextInt();
        return valor;
    }

    public static boolean ingresarBoolean(String mensaje) {
        Scanner sc = new Scanner(System.in);
        System.out.print(mensaje);
        boolean valor = sc.nextBoolean();
        return valor;
    }

    public static String calculoDescuento(double valorCompra, boolean clienteFrecuente, int edad) {
        String mensaje = " ";

        if (valorCompra > 200000 && clienteFrecuente == true) {
            mensaje = "usted aplica para el descuento";
        } else {
            mensaje = "usted NO aplica para el descuento";
        }

        if (edad > 65) {
            mensaje = "usted aplica para el descuento";
        }

        return mensaje;
    }

    public static void generarMensaje(String valorFinal) {
        String mensaje = "Para la promoción " + valorFinal;
        System.out.println(mensaje);
    }
}

Ejercicio 2A — Análisis de Consumo Diario de Agua

E2a.java
¿Qué problema intenta resolver?

Calcula el consumo promedio diario de agua por persona en un hogar a partir del consumo total de litros y la cantidad de habitantes, clasificando el resultado en adecuado o elevado.

Datos de entrada
  • Consumo del hogar: Total de litros diarios (`double`).
  • Cantidad de personas: Número de habitantes (`int`).
Proceso y Lógica Utilizada
  • Cálculo matemático: promedio = consumoHogar / personas;
  • Evaluación condicional: Si promedio <= 100, el consumo es adecuado; de lo contrario, se considera excesivo.
Resultado Esperado

Muestra el total de litros gastados, el promedio calculado por persona y la conclusión sobre si el hogar se excede o no.

Explicación Sencilla del Código

Emplea división aritmética entre un número decimal y un entero. Separa responsabilidades en funciones independientes: una para calcular el promedio (calculoPromedio) y otra para evaluar el estado (calculoConTot).

Código Java (E2a.java)
E2a.java 
import java.util.Scanner;

public class E2a {

    static void main(String[] args) {
        double consumoHogar = ingresarRealD("¿Cuántos litros de agua consumen al día en el hogar? ");
        int personas = ingresarEntero("¿Cuántas personas viven en el hogar? ");
        double promedio = calculoPromedio(consumoHogar, personas);
        String consumoTotal = calculoConTot(promedio);
        generarMensaje(consumoHogar, promedio, consumoTotal);
    }

    public static double ingresarRealD(String mensaje) {
        Scanner sc = new Scanner(System.in);
        System.out.print(mensaje);
        double valor = sc.nextDouble();
        return valor;
    }

    public static int ingresarEntero(String mensaje) {
        Scanner sc = new Scanner(System.in);
        System.out.print(mensaje);
        int valor = sc.nextInt();
        return valor;
    }

    public static double calculoPromedio(double consumoHogar, int personas) {
        double promedio = consumoHogar / personas;
        return promedio;
    }

    public static String calculoConTot(double promedio) {
        String mensaje = " ";
        if (promedio <= 100) {
            mensaje = " Su hogar tiene el consumo de agua adecuado";
        } else {
            mensaje = " Su hogar se está excediendo con el consumo de agua";
        }
        return mensaje;
    }

    public static void generarMensaje(double consumoHogar, double promedio, String consumoTotal) {
        String mensajeF = "Los litros gastados al día fueron: " + consumoHogar
                + " El promedio es de: " + promedio + consumoTotal;
        System.out.println(mensajeF);
    }
}

Ejercicio 2B — Servicio de Lavandería para Mascotas

E2b.java
¿Qué problema intenta resolver?

Calcula la tarifa del servicio de lavado para una mascota según su peso en kilogramos, aplicando una tarifa por kilo diferenciada y un descuento del 10% si la mascota pesa 10 kg o menos.

Datos de entrada
  • Peso de la mascota: Valor numérico (`double`).
Proceso y Lógica Utilizada
  • Calcula la tarifa base para peso menor o igual a 10 kg: peso * 35000.
  • Calcula la tarifa para peso mayor a 10 kg: peso * 50000.
  • Si peso <= 10, calcula el 10% de descuento y lo resta al subtotal.
Resultado Esperado

Imprime el valor total a pagar (con o sin descuento aplicado) y el detalle del descuento si aplica.

Explicación Sencilla del Código

Muestra cómo realizar operaciones aritméticas con porcentajes (`* 0.10`) y cómo utilizar estructuras if-else para manejar tarifas condicionadas por rangos numéricos.

Código Java (E2b.java)
E2b.java 
import java.util.Scanner;

public class E2b {

    static void main(String[] args) {
        double peso = ingresarRealD("Por favor ingrese el peso de su mascotica: ");
        String descuento = calculoDescuento(peso);
        generarMensaje(descuento);
    }

    public static double ingresarRealD(String mensaje) {
        Scanner sc = new Scanner(System.in);
        System.out.print(mensaje);
        double valor = sc.nextDouble();
        return valor;
    }

    public static String calculoDescuento(double peso) {
        String mensaje = " ";
        double descuento = 0.0;
        double mascotapeso10 = peso * 35000;
        double mascotapesomayor = peso * 50000;

        if (peso <= 10) {
            descuento = mascotapeso10 * 0.10;
            mascotapeso10 = mascotapeso10 - descuento;
            mensaje = "El valor total a pagar con descuento aplicado es: "
                    + mascotapeso10
                    + " y el descuento fue de: "
                    + descuento;
        } else {
            mensaje = "Usted no aplica para el descuento, el valor a pagar es "
                    + mascotapesomayor;
        }

        return mensaje;
    }

    public static void generarMensaje(String descuento) {
        System.out.println(descuento);
    }
}

Ejercicio 3B — Clasificación de Consumo

E3b.java
¿Qué problema intenta resolver?

Clasifica el nivel de eficiencia o consumo en tres categorías distintas (eficiente, moderado o alto) a partir de un valor numérico ingresado.

Datos de entrada
  • Consumo: Valor numérico (`double`).
Proceso y Lógica Utilizada

Usa una cadena de decisiones anidadas if - else if - else (escalera de decisiones):

  • Si consumo >= 15: `"Consumo eficiente"`
  • Sino, si consumo >= 10: `"Consumo moderado"`
  • Sino: `"Consumo alto"`
Resultado Esperado

Muestra en pantalla la clasificación obtenida (ej. "Clasificación: Consumo eficiente").

Explicación Sencilla del Código

Ilustra de forma clara el funcionamiento de las evaluaciones condicionales múltiples excluyentes mediante bloques else if, asegurando que se evalúe de mayor a menor restricción.

Código Java (E3b.java)
E3b.java 
import java.util.Scanner;

public class E3b {

    public static void main(String[] args) {
        double consumo = ingresarRealD("¿Cuál es el consumo de combustible? ");
        String clasificacion = calcularClasificacion(consumo);
        generarMensaje(clasificacion);
    }

    public static double ingresarRealD(String mensaje) {
        Scanner sc = new Scanner(System.in);
        System.out.print(mensaje);
        double valor = sc.nextDouble();
        return valor;
    }

    public static String calcularClasificacion(double consumo) {
        String mensaje = " ";

        if (consumo >= 15) {
            mensaje = "Consumo eficiente";
        } else if (consumo >= 10) {
            mensaje = "Consumo moderado";
        } else {
            mensaje = "Consumo alto";
        }

        return mensaje;
    }

    public static void generarMensaje(String clasificacion) {
        String mensaje = "Clasificación: " + clasificacion;
        System.out.println(mensaje);
    }
}
