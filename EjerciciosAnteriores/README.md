# Java-Ejercicios-UQ

Repositorio de ejercicios y prácticas de **Java** desarrollados para la asignatura **Lógica de Programación** del programa de **Ingeniería de Sistemas y Computación** de la **Universidad del Quindío**.

El repositorio documenta mi proceso de aprendizaje, desde los fundamentos de programación hasta conceptos progresivamente más complejos.
